# Notas de Segurança — V30.1

Esta versão adiciona expiração automática da sessão do responsável.

Ainda não é possível tratar o armazenamento local como um cofre contra alguém com acesso técnico ao navegador. A próxima etapa deverá integrar criptografia real dos dados médicos e backup protegido por senha, com migração segura e testes de recuperação.
